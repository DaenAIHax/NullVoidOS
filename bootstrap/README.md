# NullVoidOS — Bootstrap (Agent-Primary OS)

> Experimental research alpha — Vercel Labs style. Not production.

This subdirectory hosts a different research direction from the main branch:
an LFS-bootstrap path toward an **agent-primary operating system**.

Where the main branch builds a container-centric cybersecurity workbench
on Fedora Atomic, this work explores what an OS looks like when the
primary user is an AI agent from boot moment 0.

**Read [`DESIGN.md`](./DESIGN.md) for the thesis, architecture, and phase plan.**

## Status

Phase 0 — scaffolding. Nothing buildable yet.

## Relationship to main branch

The two directions coexist for now. This is exploratory; the main branch
remains the project's documented direction until/unless this matures into
a demonstrable prototype.
